# 设计：滑轮滑行中下蹲

> 对应英文/法文原文：[`2026-07-17-roller-crouch-glide-design.md`](2026-07-17-roller-crouch-glide-design.md)

## 背景和目标

机器人在滑轮向前滑行时，由按钮触发完成下蹲并恢复，既保留前进动量又保持平衡。该任务是独立技巧，不修改普通 roller locomotion。

## 选定方案

采用方案 B：命令槽携带归一化 phase，策略跟踪一个梯形高度目标，而不是让 PPO 自己猜动作时序。

受影响文件包括 `mdp.py`、新的 roller crouch env cfg、任务注册、推理脚本和测试。复用现有滑轮模型、BAM、观测、DR 和 PPO 基础。

## 梯形高度目标

一个周期分为下降、低位保持、上升和站立保持。目标躯干高度在各段线性插值；phase 循环时保持连续。play 和运行端必须以相同周期生成 phase。

## 奖励

- 跟踪目标躯干高度；
- 保持前进速度或不明显减速；
- upright、足/轮接触和横向稳定；
- 关节姿态、动作速率和能量正则；
- 防止直接坐地或摔倒。

## 训练

先固定速度和简单物理，再扩大初速度、摩擦、质量和扰动。必须用 64 env、5 iteration 冒烟测试验证 phase、奖励符号和无 NaN。

## 导出与部署

导出统一 61×14 ONNX，运行端在滑轮场景中把它装入独立槽位，并以与训练一致的 phase 触发。按钮和 CLI 标志必须与推理脚本同步。

## 风险

主要风险是高度目标不可达、phase 不一致、继承的滑行 reward 抵抗下蹲，以及策略通过减速/倒地钻奖励空子。
