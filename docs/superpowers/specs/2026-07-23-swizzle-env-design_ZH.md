# 设计：Swizzle 滑轮环境

> 对应英文原文：[`2026-07-23-swizzle-env-design.md`](2026-07-23-swizzle-env-design.md)

## 目标

训练经典对称 swizzle：两脚/轮左右开合产生向前推进，避免普通滑轮步态中的交替迈步或不对称扭动。

## 选定方案

采用方案 A：移除反 swizzle 限制，并通过左右对称和期望轮/腿关系奖励动作。沿用 roller 环境的物理、观测和 sim2real 配置。

## 结构

新增独立 env cfg 和任务注册，在 `mdp.py` 添加对称、轮运动和步态关系函数。策略仍接收速度命令，保持 61 维协议。

## 奖励配方

- 前向速度跟踪；
- 左右腿/轮镜像关系；
- 双脚持续接地；
- 抑制 yaw 和横向漂移；
- upright、动作平滑和合理姿态；
- 允许完成 swizzle 所需的髋部开合，不用普通步态惩罚压制它。

## PPO 和测试

使用 roller 相近 PPO 配置。CPU 测试锁定 reward 函数、符号、关节选择和配置；GPU smoke 验证无 NaN，再通过视频确认动作确实是 swizzle。

## 调参旋钮

前向速度权重、对称权重、feet grounded、髋 roll 幅度、动作平滑和命令范围应在首轮视频后调整。
